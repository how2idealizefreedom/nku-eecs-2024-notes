## 🔒 隐私处理说明

- 文档（`*.docx`）、表格（`*.xlsx`）、演示（`*.pptx`）中出现的真实姓名、学号已统一替换为 `[姓名]` / `[学号]`。
- 含 LaTeX 源的报告已重新编译，PDF 中不再含个人信息。
- 已剔除带有证件号的官方文件（准考证等）与含私人信息的简历/家教文件夹。

## ⚠️ 注意事项

- 本仓库为**公开**展示用途，请在推送前确认无误。
- 部分大型二进制（安装包 `*.exe/*.msi`、视频 `*.mp4`、安装用 `*.zip`）已被 `.gitignore` 忽略，不会进入版本库。
- 数学类 PDF 部分来自第三方电子书，**注意版权**，仅供个人学习。
